# 🛠️ IT Support Automation Toolkit

A unified IT support dashboard covering all three lines of support —
built with Python and Streamlit.

🔗 **Live Demo:** [Click here to open the app](YOUR_STREAMLIT_URL)

---

## 📋 What This Project Covers

### 🎫 1st Line — Helpdesk Ticketing System
- Create and manage support tickets
- Priority levels: Low / Medium / High / Critical
- Status tracking: Open / In Progress / Closed
- SQLite database for persistent storage
- Filter tickets by status and priority

### 🌐 2nd Line — Network Diagnostic Tool
- Ping any host or IP address
- Port scanner — check open/closed ports
- DNS lookup — A records, MX records, TXT records
- Common ports reference guide

### 📊 3rd Line — System Monitoring Dashboard
- Live CPU usage with per-core breakdown
- RAM and swap memory usage
- Disk usage with alerts at 80%+
- Top 10 processes by CPU
- Network I/O statistics
- System info and uptime
